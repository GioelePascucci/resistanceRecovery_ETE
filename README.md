# Correlated evolution of thermal tolerance and egg size links resistance and recovery to extreme heat in amphibians



## Description

This repository contains the raw data, phylogenetic information, and R scripts necessary to reproduce the analyses and figures of the manuscript "Correlated evolution of thermal tolerance and egg size links resistance and recovery to extreme heat in amphibians" (Pascucci, G., Tejedo, M., Gvoždík, L.).

## Abstract
We tested 83 species of amphibians (Anura, 43; Caudata, 40), representing 19 families. Using phylogenetic comparative analyses across multiple evolutionary models, we investigated associations between critical thermal maximum (CTmax) and three life-history traits: clutch size, egg size, and age at maturity, while controlling for geographic gradients and body size (snout-vent length).

## Data collection & processing
Primary physiological and life-history trait data were compiled from published literature and established databases (for data format specification and complete list of references see Repository structure below).
Thermal tolerance values were standardized for acclimation temperature, duration, and physiological endpoints using `heatTolerance.R`.
Species range maps and occurrence records were retrieved from IUCN (2025) and GBIF (gbif.org, 2026), then integrated with the elevation raster from WorldClim 2.1 (Fick & Hijmans, 2017), using `speciesRange.R` for coordinates cleaning and data merging.
Phylogenetic comparative analyses (e.g., PGLS and multivariate PGLS) based on the Jetz and Pyron (2018) phylogeny were implemented in R v4.5.3 (R Core Team, 2026). The complete analysis workflow and R package environment are provided in `main.R` and `sessionR_info.txt`, respectively.

## Setup and analysis workflow

To successfully replicate the study, please follow the steps below in the exact order.

### Step 1: Download required external data

Before running any scripts, you must download the following external datasets and place them directly into the `/data` directory (keep .zip files compressed).
<p></p>

1. **AmphiTherm dataset** (Pottier et al., 2025)
   * Download version v1.0.1 `.zip` file from [Zenodo](https://doi.org/10.5281/zenodo.16751427).
<p></p>

2. **IUCN Amphibian range maps** (IUCN, 2025; accessed August 2026)
   * Download the shapefile `.zip` for all amphibians from the [IUCN Red List](https://www.iucnredlist.org/resources/spatial-data-download#amphibians).
<p></p>

3. **WorldClim elevation raster** (Fick & Hijmans, 2017)
   * Download version 2.1, elevation data (30-seconds resolution) from [WorldClim](https://www.worldclim.org/data/worldclim21.html).
<p></p>

### Step 2: Execute scripts

Once all data files are located in the `/data` folder, run the R scripts in the following sequence:
<p></p>

1. **`heatTolerance.R`**: Standardize the thermal tolerance data.
<p></p>

2. **`speciesRange.R`**: Calculate the spatial distribution and elevation ranges for the species.
<p></p>

3. **`main.R`**: Execute the core phylogenetic and statistical analyses and produce the manuscript figures.
